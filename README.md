# Student Management System

## Project Description
The Student Management System is designed to manage student details, courses, attendance, examinations, and results efficiently.

## Objectives
- Manage student information.
- Maintain course details.
- Track student attendance.
- Schedule examinations.
- Manage student marks and results.

## Modules
1. Student Registration
2. Course Management
3. Attendance Management
4. Examination Management
5. Results Management

## Project Management Tool
Jira

## Methodology
Scrum Agile Methodology

## Epics
- Student Registration
- Course Management
- Attendance Management
- Examination
- Results Management

## Advantages
- Reduces manual work.
- Improves data accuracy.
- Saves time.
- Organizes student records.
- Makes academic management easier.

## Conclusion
The Student Management System provides an organized way to manage student information and academic activities. Jira helps track tasks, manage sprints, and monitor project progress.
